## Finding Files

Each assignment has its own folder. Start with its `README.md`, then open the individual parts.

```text
digital-technologies/
└── task-03-python-store/
    ├── README.md                 Assignment overview
    ├── originals/                Original task documents
    ├── part-1-planning/          Planning and pseudocode
    ├── part-2-coding/            Python code and development screenshots
    └── part-3-reflection/        Peer feedback and reflection
```

## Adding Another Assignment

1. Create an assignment folder under the relevant subject, such as `digital-technologies/task-04-project-name/`.
2. Add a `README.md` with the assignment title, requirements, progress and file links.
3. Add the task documents, individual parts, code and screenshots as needed.
4. Update the assignment lists on this page and in the subject directory. Mark finished assignments as "Complete".

Create folders for new subjects, such as `mathematics/` or `physics/`, when there are assignments to add.

To share one assignment, send the link to its folder.
