## 文件怎么找

每份作业都有独立文件夹。进入作业文件夹后，先阅读 `README.md`，再查看各部分内容。

```text
digital-technologies/
└── task-03-python-store/
    ├── README.md                 作业总文档
    ├── originals/                原始题目
    ├── part-1-planning/          规划与伪代码
    ├── part-2-coding/            Python 代码与开发截图
    └── part-3-reflection/        真实反馈与反思
```

## 添加下一份作业

1. 在相应学科下新建作业文件夹，例如 `digital-technologies/task-04-project-name/`。
2. 在作业的 `README.md` 中写清名称、要求、进度和文件链接。
3. 按实际内容添加题目、各 Part、代码和截图。
4. 更新本页与学科目录中的作业列表。已完成的作业标注“已完成”。

新学科可以另建文件夹，例如 `mathematics/`、`physics/`；有实际作业后再加入目录。

需要分享某一份作业时，直接分享它的文件夹链接即可。
